# 👨‍💻 Portfólio Pessoal

Projeto desenvolvido para criar meu portfólio pessoal como parte dos meus estudos em **Análise e Desenvolvimento de Sistemas** e da minha transição de carreira para a área de Tecnologia da Informação.

## 📋 Sobre o projeto

O **Portfólio Pessoal** apresenta minha trajetória profissional, formação acadêmica, tecnologias em estudo e projetos desenvolvidos durante minha jornada de aprendizado em programação e desenvolvimento web.

Esta primeira versão foi desenvolvida utilizando **HTML5**, com foco na estruturação do conteúdo, semântica e acessibilidade básica.

## 🎯 Objetivos

* Praticar os fundamentos do HTML5;
* Utilizar HTML semântico;
* Organizar informações pessoais e profissionais;
* Criar navegação entre as seções da página;
* Apresentar projetos desenvolvidos durante os estudos;
* Desenvolver uma base para futuras melhorias com CSS e JavaScript.

## 🛠️ Tecnologias utilizadas

* HTML5
* Git
* GitHub
* Visual Studio Code

## 📚 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos como:

* Estrutura básica do HTML5;
* Cabeçalhos (`h1`, `h2`, `h3`);
* Parágrafos;
* Links internos e externos;
* Listas;
* Estrutura semântica;
* `header`;
* `nav`;
* `main`;
* `section`;
* `article`;
* `aside`;
* `footer`;
* Identificadores (`id`);
* Navegação interna com âncoras;
* Organização e acessibilidade básica do conteúdo.

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/diego-nascimento-passos/portfolio-pessoal.git
```

2. Acesse a pasta do projeto:

```bash
cd portfolio-pessoal
```

3. Abra o arquivo `index.html` no navegador.

Também é possível abrir o projeto diretamente pelo **Visual Studio Code** e utilizar uma extensão como o **Live Server** para visualizar a página durante o desenvolvimento.
